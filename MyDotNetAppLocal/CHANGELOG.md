# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-02

### Added
- Modern weather application with responsive design
- Real-time weather data integration with OpenWeatherMap API
- 5-day weather forecast functionality
- Interactive search for any city
- Mobile-optimized interface
- Docker containerization support
- Azure deployment configuration
- Comprehensive documentation

### Features
- Current weather display (temperature, feels like, humidity, wind, pressure)
- Weather icons and descriptions in Swedish
- Gradient background with glass morphism effects
- CORS support for API access
- Mock data fallback when API is unavailable
